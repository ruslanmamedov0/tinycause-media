# Tiny Cause media

Rendered video files for the Tiny Cause / Küçük Sebep Shorts channels.
These videos are already public on YouTube; this repo only hosts the files for the posting scheduler.


## Gözətçi
Instagram Reels və YouTube şərhləri `watcher.yml` ilə dəqiq vaxtında dərc olunur (kompüter lazım deyil). Növbələr: `ig_queue.json`, `comment_queue.json` (publish_all əlavə edir); vəziyyət: `state/`. Açarlar GitHub Secrets-dədir.
